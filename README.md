# MERN Task Manager

A full-stack task management application built with MongoDB, Express.js, React, and Node.js. The project demonstrates CRUD operations, REST API integration, state management, and client-server communication in a modern MERN architecture.

## Features

* Create, update, delete, and manage tasks
* Mark tasks as completed
* RESTful API architecture
* MongoDB data persistence
* React-based frontend
* Express and Node.js backend
* Responsive user interface
* Real-time UI updates after API operations

## Tech Stack

### Frontend

* React
* JavaScript
* CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB
* Mongoose

## Architecture

      ▼
